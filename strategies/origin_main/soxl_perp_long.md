# soxl_perp_long: long-only paper

## 身份与状态

| 项目 | 值 |
|---|---|
| 来源 | `origin/main@3c2253f` |
| 账户 | `soxl_perp_long` |
| 产品 | Binance `SOXLUSDT` USD-M Futures 行情的模拟账户 |
| 策略名 | `soxl_long_atr32x3_v1` |
| 用途 | 与实盘信号参数一致的 long-only paper 对照 |

## 信号参数

| 参数 | 值 |
|---|---:|
| 方向 | 仅做多 |
| K 线周期 | 15 分钟 |
| 预热 | 200 根官方 K 线 |
| ATR | Wilder ATR(32) |
| ATR 跟踪倍数 | 3.0 |
| 趋势效率 | 8 根，最低 0.25 |
| 反向确认 | 0.0 ATR；仅做多路径不反手 |
| 动作锁 | 每根 15 分钟 K 线最多一次策略动作 |
| 盈利保护 | 关闭（0.0/0.0 ATR） |
| 延续重入 | Paper 路径未启用 |

价格从递归 ATR 跟踪线下方穿到上方且趋势效率通过时开多。持有多仓后，下穿跟踪线只平多；
平仓后保持空仓，等待下一次有效上穿，不开空、不自动反手。

## 风险与成交

| 参数 | 值 |
|---|---:|
| 模型 | Futures paper |
| 交易所杠杆模型 | 2x isolated |
| 仓位比例 | 62.5% 权益 |
| 目标名义敞口 | 1.25x 权益 |
| Taker 手续费假设 | 5 bps |
| 滑点假设 | 2 bps |
| 最小名义金额 | 5 USDT |

Paper 在信号后的下一笔持久化 Tick 模拟成交，成本和滑点是固定假设，不等同于实盘成交。

## 初始化与状态

新 paper 账户可执行一次启动趋势对齐：若当前价格已在 ATR 线上方且趋势过滤通过，可以直接
建立多仓。策略运行状态持久化，普通重启会先恢复状态，不应重复消费启动对齐。该初始化语义
与实盘“禁止启动追入”不同，因此即使参数相同，两条账户路径也可能在同一时刻持有不同仓位。
