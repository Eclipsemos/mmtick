## 信号参数

| 参数 | 值 |
|---|---:|
| 方向 | 多空 |
| K 线周期 | 15 分钟 |
| 预热 | 200 根官方 K 线 |
| ATR | Wilder ATR(21) |
| ATR 跟踪倍数 | 4.0 |
| 趋势效率 | 8 根，最低 0.25 |
| 反向确认 | 0.25 ATR |
| 动作锁 | 每根 15 分钟 K 线最多一次策略动作 |
| 盈利保护 | 2.0 ATR 激活，距有利极值 0.5 当前 ATR 跟踪 |
| 延续重入 | Paper 路径未启用 |

价格穿越递归 ATR 跟踪线时产生方向信号，新开仓必须通过趋势效率过滤。反向穿越先用
`reduce_only` 平掉现有仓位，不在同一信号反手；平仓成交后的下一根 K 线若沿反方向继续超过
0.25 ATR，才允许建立反向仓位。

盈利保护在持仓有利移动达到 2.0 倍入场 ATR 后激活，再以距持仓期间有利极值 0.5 倍当前 ATR
的单向保护线退出。保护线不后退，触发时只平仓，不在同一动作反手。

## 风险与成交

| 参数 | 值 |
|---|---:|
| 模型 | Futures paper |
| 交易所杠杆模型 | 2x isolated |
| 仓位比例 | 62.5% 权益 |
| 目标名义敞口 | 1.25x 权益 |
| Taker 手续费假设 | 5 bps |
| 滑点假设 | 2 bps |
| 最小名义金额 | 5 USDT |

Paper 在信号后的下一笔持久化 Tick 模拟成交，并计入固定费用、滑点和历史资金费。

## 初始化与状态

新 paper 账户允许一次启动趋势对齐。价格在 ATR 线上方时可开多，在线下时可开空，前提是
趋势过滤通过且没有持仓或待处理订单。策略、反向确认和盈利保护状态均应随账户持久化，普通
重启不应重新执行启动对齐。
