# BTC B&H 超额研究主报告

## 当前冻结候选

`BTCUSDT` 日线 SMA 8/40：当价格低于 SMA40 且 SMA8 < SMA40 时目标暴露为 `-0.1X`，其余状态为 `+1.5X`。账户使用 50% 现货、50% USD-M 合约抵押；信号在已完成日线收盘确认，下一根 15m 开盘调仓。合约执行杠杆上限固定为 **3X**，不允许超过该上限。压力成本为 10 bps 手续费、5 bps 滑点和历史 Funding。

上述是永续主样本的历史冻结基线；跨数据源的保守 bear-flat（熊市 0X、不做空）版本及
SMA12/40 Challenger 单独审计，不能与该基线混合比较或事后择优替换。

### 严格执行口径修正

后续复核确认，主报告中部分拼接结果采用了聚合日线执行，不能直接代表“日线信号、下一根 15m 开盘”的严格执行协议。严格 15m 复核的权威结果见[专门报告](../../btc_hysteresis_15m_full/2026-09-02/README.md)：2020–最新收益 **+2,643%** 对 B&H **+973%**，CAGR **64.27%** 对 **42.72%**，最大回撤 **-63.89%**，最高盘中有效杠杆 **1.804X**，逐年跑赢 B&H **6/7 年**。此前 +11,103% 为日线拼接敏感性结果，不再作为主收益数字。

严格 15m 配对 Bootstrap 的 7/30/90 日年化超额 P05 为 **-10.64% / -9.31% / -6.92%**；因此不能沿用聚合日线报告中的正 P05 结论。严格执行统计显示历史收益优势仍存在，但稳健性证据明显较弱。

并用盘中低点审计有效杠杆。

该候选在 Research / Validation / OOS 的压力超额分别为 **+196.47pp / +64.80pp /
+18.41pp**，Full CAGR 为 **64.62%**（B&H 42.81%），历史盘中最高杠杆 **2.996X**。
但 2019 独立留出落后 **14.19pp**；7/30/90 日区块 Bootstrap 的年化超额第 5 百分位
分别为 **-13.61% / -10.06% / -7.83%**。因此它是更好的研究候选，不是已证明的 Edge。
详见[斜率门槛回放](../../btc_daily_sma_slope_gate_3x/2026-09-02/README.md)和[统计审计](../../btc_daily_sma_slope_gate_audit/2026-09-02/README.md)。

在此基础上加入 Funding 空头门槛（空头仅在最新已公布 Funding 高于阈值时启用）后，
预限定的 18 个组合中，开发期评分选择 `slope5d-funding>0.0001`。该版本的滚动与
Bootstrap 审计显示 1/2/3 年滚动胜率为 68.57% / 66.67% / 80.00%，90 日区块中超过
B&H 的概率为 87.22%，但年化超额 P05 仍为 -6.22%，且 2019 留出落后 13.44pp。
它改善了多数历史重采样结果，但仍未通过正下界和独立留出门槛。详见
[Funding 空头门槛回放](../../btc_funding_short_gate_3x/2026-09-02/README.md)和
[Funding 门槛统计审计](../../btc_funding_short_gate_audit/2026-09-02/README.md)。

## 2017–2026 跨数据源连续路径

为扩大前置验证，补充了 Binance BTCUSDT 现货 2017-08 至 2019-12 的 867 根日线，并与
USD-M 2020-01 至最新的 2,436 根日线拼接。固定测试不做空的 `SMA8/40 bear-flat`（牛市
1.5X、熊市 0X、50% 现货、2X 下单缓冲）后，2017-10 至最新压力收益为 **+10,258.39%**，
同期 B&H **+1,667.73%**，超额 **+8,590.66pp**；最大回撤 **-80.21%** 对 B&H **-83.48%**，
最高盘中有效杠杆 **2.488X**。分段超额为：2017–2019 **+188.74pp**、2020–2022
**+194.05pp**、2023–2024 **+27.16pp**、2025–最新 **+33.96pp**。

连续路径审计的 1/2/3 年滚动窗口超过 B&H 的比例为 **77.32% / 77.65% / 90.41%**，
90 日区块 Bootstrap 超过 B&H 的概率为 **93.26%**；但年化超额 P05 仍为 **-1.79%**。
这比仅用永续样本的证据更强，但仍不能证明统计显著，且现货与永续的成交/资金费率口径
不同。详见[拼接回放](../../btc_stitched_3x/2026-09-02/README.md)和[拼接统计审计](../../btc_stitched_3x_audit/2026-09-02/README.md)。

### 固定参数 Challenger：SMA12/40

网格阶段仅使用 2017–2024 选定 SMA12/40，随后冻结参数并对 2025–最新及全样本只读审计。
机制仍为日线 bear-flat（熊市空仓、非熊市 1.5X），50% 现货 + 50% USD-M 抵押，2X
下单缓冲；因此历史盘中有效杠杆最高 **2.488X**，满足 3X 硬上限。2017–10 至最新
压力收益为 **+11,316.96%**，B&H **+1,667.73%**，最大回撤 **-80.26%**。

固定候选的滚动窗口超过 B&H 比例为：1/2/3 年 **74.23% / 90.59% / 90.41%**；
90 日区块 Bootstrap 超过 B&H **93.79%**，但年化超额 P05 为 **-1.36%**（7 日、30 日
分别为 -5.86%、-4.66%）。因此 SMA12/40 的历史结果优于 SMA8/40 的部分统计量，
却仍不能排除未来落后 B&H；不得据此提高杠杆或转入实盘。详见
[SMA12/40 审计](../../btc_stitched_sma12_40_audit/2026-09-02/README.md)和

该组合是目前较平衡的收益/回撤候选，但 2024 年仍落后 B&H，不能视为已证实 Edge。

### 跨时代滞后确认 Challenger：SMA10/40 Hysteresis

在拼接数据上对一个预先限定的抗噪机制进行了独立诊断：进入熊市必须连续 2 根 bearish
日线，恢复只需 1 根 non-bearish 日线；非熊市暴露 1.5X，熊市 0X。该规则只使用当前
及过去已完成日线，未回填信号时间。

现货 2017–2019 与 USD-M 2020–最新的压力回放收益为 **+14,821.69%**，B&H **+1,667.73%**；
最大回撤 **-74.65%** 对 **-83.48%**，最高盘中有效杠杆 **2.456X**。四个分段（2017–2019、
2020–2022、2023–2024、2025–最新）均超过同期 B&H；1/2/3 年滚动胜率为 **80.41% /
80.00% / 91.78%**，90 日 Bootstrap 超过 B&H **96.42%**，年化超额 P05 **+2.07%**。
不过 7 日和 30 日 P05 仍分别为 -1.91% 和 -0.21%，而且该机制尚未完成严格的预注册
参数选择和 2026-09-03 之后前向观察，因此仍是 Challenger，不是实盘批准版本。详见
[跨时代审计](../../btc_stitched_sma10_40_hysteresis/2026-09-02/README.md)和
[滞后确认参数网格](../../btc_stitched_hysteresis_grid/2026-09-02/README.md)。

尾部依赖审计显示，移除最佳 5 个相对收益日后年化超额仍约 **+10.83%**，移除最佳
10 日后仍约 **+2.69%**；移除最佳 20 日后才转负（-9.22%）。这比原始 SMA8/40
候选的尾部依赖更弱，但仍不能替代真实前向观察。

### 严格有效杠杆 Challenger：宏观门槛 + 波动率缩放

为避免 3X 开盘仓位在亏损后的盘中杠杆越界，新增 2.5X Futures 开盘上限，并把
Research/Validation 盘中有效杠杆超过 3X 的组合直接淘汰。开发期选择的
`4h-24-48-96-192-macro1200-vol360-target1` 在压力成本下 Full CAGR **50.80%**，
B&H **42.78%**；OOS 超额 **+6.12pp**，Full 最大回撤 **-73.48%**，盘中最高有效杠杆
**2.590X**。但 Bootstrap 年化超额 P05 为 **-12.76% / -13.29% / -12.59%**（7/30/90日），
仍不能视为统计显著或实盘候选。详见[严格有效杠杆审计](../../btc_macro_vol_strict_cap/2026-09-02/README.md)。

作为跨资产反例，同样的 SMA10/40 滞后确认直接应用于 ETHUSDT（2020–2026-08-28）仅有
约 **+1.12pp** 的全样本超额，最大回撤 **-83.93%** 高于 ETH B&H **-81.90%**；7/30/90
日 Bootstrap 超过 B&H 的概率约 **50.75% / 50.34% / 50.41%**，年化超额 P05 约
**-29%**。因此当前证据支持“BTC 路径特异性候选”，不支持跨币种通用策略。

OOS 超额为 **+41.36pp**，1/2/3 年滚动超过 B&H 比例为 **67.14% / 71.93% / 82.22%**。
不过 2022 和 2024 年仍落后 B&H，Bootstrap 年化超额 P05 为 **-12.45% / -10.66% /

### Funding-aware 等权集成 Challenger

在上述固定集成上增加单一可解释过滤器：当最新已公布 Funding 高于阈值时，将额外多头
暴露降回 1X。阈值仅在 Research/Validation 网格中选择，结果为 **0.02%**。严格 2.5X
开盘上限下，Full 收益 **+3,959.09%**、CAGR **74.21%**，B&H CAGR **42.78%**；OOS
超额 **+41.36pp**，最大回撤 **-74.41%**，盘中最高有效杠杆 **2.694X**。90 日 Bootstrap
超过 B&H 的概率为 **91.93%**，但年化超额 P05 仍为 **-3.42%**，所以它是当前最强的
研究 Challenger，仍需冻结后的前向观察。详见[Funding-aware 集成审计](../../btc_daily_sma_ensemble_funding/2026-09-02/README.md)。

成本敏感性显示，在公平地给 B&H 也计入入场/出场成本后，默认 10+5 bps 下 2.5X 开盘上限
仍有 Research/Validation/OOS/Full 超额 **+277.57% / +81.18% / +41.61% / +2,986.23%**；
即使压力提高到 20+10 bps，Validation 和 OOS 超额仍分别为 **+4.62pp / +32.68pp**。
这说明结果并非只在单一成本假设下成立，但不足以证明未来统计显著。详见
[成本/杠杆敏感性](../../btc_daily_sma_ensemble_funding_sensitivity/2026-09-02/README.md)。

### 严格 3X 因果 Walk‑Forward：SMA10/40 迟滞 1.25X

为避免只依赖固定全样本回放，新增了真正的年度 Walk‑Forward：每个测试年度只使用此前
完整年度选择 fast SMA、熊市确认天数、恢复天数和主动暴露，测试年度完全留出。严格 3X
版本在 2019–2026 的 8 个测试年度中有 **6/8** 年超过 B&H，且 **6/8** 年回撤更优；
复合收益 **+4,788%** 对 B&H **+1,993%**，所有测试年度盘中有效杠杆均低于 3X。

排除早期训练样本较短的 2019–2020 后，2021–2026 的严格版本仍有 **4/6** 年超过 B&H，
复合收益 **+404%** 对 **+167%**。这比事后固定最优参数更接近可复现流程，但年度样本仍少，
不能替代长期前向观察。详见[年度 Walk‑Forward](../../btc_hysteresis_walk_forward/2026-09-02/README.md)
和[严格训练样本版本](../../btc_hysteresis_walk_forward/2026-09-02-start2021/README.md)。

对上述 8 个测试年进行独立重抽样后，6/8 年跑赢 B&H，但精确单侧符号检验 `p=0.1445`，
年度超额 95% 重抽样区间为 **-9.33% 至 +40.64%**；因此方向偏正但尚未达到统计显著。
详见[Walk‑Forward 统计审计](../../btc_hysteresis_walk_forward/2026-09-02/stats/README.md)。

### 同杠杆基准审计

将候选与相同抵押结构下的 1.0X、1.25X、1.5X 被动买入持有比较后，候选 Full 收益为
**+11,103%**，而被动 1.25X 为 **+953%**；候选最大回撤 **-70.10%**，被动 1.25X 为
**-88.12%**。候选最高盘中有效杠杆为 **1.927X**。被动杠杆基准在抵押品亏损后出现超过
3X 的瞬时杠杆，因此不满足严格 3X 合规，只能作为风险参考，不能作为合法实盘基准。
这表明候选优势主要来自熊市降仓和避免 Funding/亏损累积，而不是单纯提高杠杆。详见
[同杠杆基准审计](../../btc_hysteresis_leverage_benchmark/2026-09-02/README.md)。

## 反例与限制

未参与原研究的 2019-10-18 至 2019-12-31 留出段落后 B&H 6.97 个百分点，说明策略不是跨所有阶段都有效。Bootstrap 的年化超额下界为负；移除最佳 5 个相对收益日后，Full 年化超额也转负。最大历史回撤约 70%。

测试过的回撤过滤器和低周期趋势过滤器均降低了回撤，但在 Validation 明显落后 B&H，因此没有加入冻结版本。3X 是硬上限，不代表收益稳定性；抵押品亏损和盘中价格路径可能使有效杠杆接近上限，必须单独监控。
