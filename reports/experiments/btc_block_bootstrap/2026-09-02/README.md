## 结论

熊市部分底仓挑战者是收益领先者，但尾部回撤风险最高；等权组合牺牲部分超额概率，换取更低的极端回撤概率。
所有策略在7/30/90日区块下的年化超额P05均为负，因此历史数据尚不能提供95%把握的正超额下界。
策略状态保持 **FORWARD_TESTING_REQUIRED**；Bootstrap不能替代2026-09-03之后的真实前向观察。
